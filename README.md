# НАРГИЛИЯ ПРОДАЖИ

Приложение для мотивации продаж сотрудников кальянной.

## 🚀 Деплой на Vercel (самый быстрый способ)

### Вариант 1: Через GitHub
1. Создайте новый репозиторий на GitHub
2. Загрузите все файлы из этой папки в репозиторий
3. Зайдите на [vercel.com](https://vercel.com) и авторизуйтесь через GitHub
4. Нажмите **"Add New Project"**
5. Выберите ваш репозиторий
6. Нажмите **"Deploy"**
7. Через 1-2 минуты получите ссылку вида `nargilya-sales.vercel.app`

### Вариант 2: Через Vercel CLI
```bash
npm install -g vercel
cd nargilya-sales
vercel
```

### Вариант 3: Drag & Drop на Netlify
1. Выполните локально: `npm install && npm run build`
2. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop)
3. Перетащите папку `build` на страницу
4. Получите ссылку мгновенно

## 📱 Установка как приложение на телефон
После деплоя откройте ссылку на телефоне → в браузере нажмите **"Добавить на главный экран"** — приложение будет работать как обычное приложение.

## ⚙️ Локальный запуск
```bash
npm install
npm start
```
Откроется на http://localhost:3000
